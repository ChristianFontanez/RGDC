# RGDC Website

Source for the Rollins Game Dev Club site, hosted via GitHub Pages from this branch.

Built on the [Hyperspace](https://html5up.net/hyperspace) template by HTML5 UP — plain static HTML/CSS/JS, no build step required.

## Structure

- `index.html` — homepage
- `generic.html` — starter content page (duplicate this for new pages like curriculum, events, join)
- `elements.html` — reference page showing all available UI components (buttons, forms, tables, etc.)
- `assets/` — CSS, JS, fonts
- `images/` — template placeholder images (swap these out)

## Local preview

Just open `index.html` in a browser — no server or build step needed.
